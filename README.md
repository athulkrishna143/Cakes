# L’Atelier Sucré — Interactive 3D Cake Studio & Bakery Ordering App

A full-stack interactive 3D Cake Studio & Custom Bakery Ordering web application built with **React**, **Vite**, **Tailwind CSS**, **Three.js**, and **React Three Fiber**.

## Quick Start

```bash
npm install
npm run dev
```

## Features
- **Procedural 3D Cake Engine**: 1–3 tiers (6", 8", 10"), round or square silhouettes, smooth buttercream / rustic / satin fondant / semi-naked textures, two-tone ombré tiers, glossy randomized ganache/caramel drips, instanced shell borders, procedural berries/macarons/gold leaf/sprinkles/chocolate shards, animated candles, and live high-DPI canvas surface inscriptions.
- **5-Step Customizer**: Size & Sponge, Frosting, Drips & Piping, Toppings, and Custom Inscription & Dietary Notes.
- **Dynamic Pricing & Servings**: Real-time INR (`₹`) and USD (`$`) pricing breakdown and slice estimates.
- **Checkout & 48h Lead Time**: Captures a PNG screenshot of the 3D WebGL canvas, enforces a 48-hour minimum bakery lead time, and stores orders.
- **Baker Kitchen Dashboard (`/admin`)**: View incoming orders, inspect the customer's configuration checklist, and load any order directly into the 3D viewer.
